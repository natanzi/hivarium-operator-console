<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator form to repository | Untrusted token amounts, references, reasons, and customer IDs cross into mutation rules. |
| localStorage v2/v3 to canonical DataStore | Browser-controlled or corrupt JSON crosses the migration boundary. |
| derived balance to UI | The balance projection is the single source of truth for prepaid state. |

## STRIDE Threat Register (ASVS Level 1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | migrateStore v2→v3 | high | mitigate | Validate record shapes, preserve every known collection, derive opening-credit IDs/references from the arrangement ID, guard with existingIds, and test positive/zero/corrupt payloads (ASVS V5 input validation). |
| T-02-02 | Tampering | addCreditGrant | high | mitigate | Revalidate customer/prepaid references, positive whole tokens, and required trimmed reference at the repository boundary through pure rules before one atomic write (ASVS V5). |
| T-02-03 | Tampering | derived balance | high | mitigate | Balance is always the pure signed sum of immutable transactions; no stored counter exists; unit tests prove arithmetic and empty-ledger zero (LEDG-03). |
| T-02-04 | Repudiation | credit mutation | medium | mitigate | Named-customer confirmation previews the resulting balance; every credit appends an immutable transaction with deterministic ID, occurredAt, reference, and reason in the same write (SAFE-02). |
| T-02-05 | Information disclosure | localStorage | medium | accept | Prototype boundary retains deterministic fictional data only; no real financial data or network transmission is introduced (ASVS V8 client-side data protection). |
| T-02-06 | Denial of service | malformed persisted arrays / huge values | low | mitigate | Bounded shape normalization, deterministic seed fallback, and whole-token range validation prevent render crashes and absurd balances. |
</threat_model>
