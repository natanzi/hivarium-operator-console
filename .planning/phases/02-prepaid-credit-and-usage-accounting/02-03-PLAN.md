## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator filter inputs to statement projection | Untrusted date ranges, agent product IDs, and transaction-type values cross into the statement query. |
| persisted ledger/usage arrays to statement rows | Browser-controlled or corrupt JSON crosses into the derived statement projection. |
| derived statement to UI | The full-account running balance is the single source of truth for every row and the selected-period summary. |

## STRIDE Threat Register (ASVS Level 1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-14 | Tampering | projectAccountStatement | high | mitigate | Derive full-account running balances in ascending order first; filters apply to displayed rows only and never recalculate a row's resulting balance (Pattern 4, Pitfall 4, LEDG-05). |
| T-02-15 | Tampering | date-range filter | high | mitigate | Normalize inclusive start/end boundaries once; invalid ranges show the documented error and keep the last valid result; boundary rows are covered by tests (USGE-03, A1). |
| T-02-16 | Tampering | sumPeriodUsage / groupUsageByAgent | high | mitigate | Net consumption and per-agent totals are pure aggregations of immutable usage effects; a fully reversed debit contributes zero; no stored consumption counter exists (D-14, USGE-04). |
| T-02-17 | Repudiation | statement rows | medium | mitigate | Every row exposes type, signed amount, full-account resulting balance, timestamp, reference, and agent/reversal detail from immutable transactions; rows are never editable or deletable (D-04, LEDG-05). |
| T-02-18 | Information disclosure | localStorage | medium | accept | Prototype boundary retains deterministic fictional data only; no real financial data or network transmission is introduced (ASVS V8 client-side data protection). |
| T-02-19 | Denial of service | malformed persisted arrays / huge values | low | mitigate | Bounded shape normalization, deterministic seed fallback, and whole-token range validation prevent render crashes and absurd statement values. |
</threat_model>
