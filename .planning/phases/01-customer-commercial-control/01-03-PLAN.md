<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator UI to repository mutations | Untrusted form values and confirmation intent cross into commercial/access state changes. |
| route parameter to repository lookup | Untrusted customer/product identifiers select locally stored records. |
| stored free text to rendered UI | Customer notes, names, reasons, and catalog descriptions are displayed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11 | Spoofing | destructive confirmation subjects | medium | mitigate | Resolve names from canonical IDs, name exact customer/model/agent, state immediate/scheduled consequence, and test the dialog before mutation. |
| T-01-12 | Tampering | double submit/dirty close | medium | mitigate | Disable during commit, route mutation once, retain entered values on error, and require explicit discard only for dirty forms. |
| T-01-13 | Information disclosure | route lookup and rendered text | low | mitigate | Render only repository-selected local records, use React text escaping, preserve stable not-found states, and add no network or HTML injection surface. |
| T-01-14 | Repudiation | Activity presentation | medium | mitigate | Display canonical timestamp, source/operator, subject, result, record ID details, and causal links directly from immutable events. |
| T-01-15 | Elevation of privilege | agent/customer reverse view | medium | mitigate | Keep catalog/detail read-only; all mutations remain on validated customer flows behind the existing private perimeter. |
| T-01-16 | Denial of service | long/large presentation values | low | mitigate | Bound tables/tabs, wrap or accessibly truncate values, forbid page overflow, and test long fixtures. |
</threat_model>
