## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator form to repository | Untrusted money, date, customer ID, and product ID values cross into mutation rules. |
| localStorage v1/v2 to canonical DataStore | Browser-controlled or corrupt JSON crosses the migration boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | migrateStore | high | mitigate | Validate record shapes, preserve known collections, use stable source-derived IDs, make migration idempotent, and test corrupt/partial payloads. |
| T-01-02 | Tampering | saveCommercialArrangement/grantAgentAccess | medium | mitigate | Revalidate customer/product references, cents, and ISO date ordering at repository boundary before one atomic write. |
| T-01-03 | Repudiation | ActivityEvent append | medium | mitigate | Append stable event ID, occurredAt, source, subject IDs, resulting state, and causation ID in the same write. |
| T-01-04 | Information disclosure | localStorage | medium | accept | Phase boundary explicitly retains the existing single-browser demo adapter; no new sensitive fields or network transmission are introduced. |
| T-01-05 | Denial of service | malformed persisted arrays | low | mitigate | Bounded shape normalization and deterministic seed fallback prevent render crashes. |
</threat_model>
